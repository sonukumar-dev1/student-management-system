# Student Management System – Frontend

A modern and responsive Student Management System frontend built using React.js and Vite.

## Overview

The Student Management System provides separate interfaces for students and administrators to manage student information securely.

## Technology Stack

- React.js – Frontend library
- Vite – Development and build tool
- React Router DOM – Client-side routing
- Axios – HTTP requests
- CSS – Styling and responsive design

## Features

### Student
- Student Registration
- Student Login
- Student Dashboard
- View Profile
- Update Profile
- Secure Logout

### Admin
- Admin Login
- Admin Dashboard
- View All Students
- View Student Details
- Update Student Information
- Delete Student
- Secure Logout

## Project Setup

### 1. Install Dependencies

```bash
npm install
```

### 2. Start Development Server

```bash
npm run dev
```

### 3. Build for Production

```bash
npm run build
```

## Backend Connection

The frontend communicates with the Student Management System backend through REST APIs.

Backend development URL:

`http://localhost:5000`

## Development Server

Frontend development URL:
